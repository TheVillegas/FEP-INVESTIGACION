# Documentación de trabajo

Usá `docs/` para notas de investigación, resúmenes de fuentes, borradores revisables y material de apoyo que el equipo necesite compartir.

Los entregables finales deben ubicarse donde el equipo acuerde y las indicaciones del curso requieran; este repositorio no impone una estructura adicional. Mantené separados los apuntes en proceso de los archivos listos para entregar y conservá trazabilidad de las fuentes y revisiones.

La plantilla [`templates/research-log.md`](templates/research-log.md) sirve para registrar hallazgos y el uso efectivo de IA.
